# NN.ASM — 8086 手写数字识别神经网络架构说明

一个用**纯 8086 汇编**实现的 LeNet 风格卷积神经网络（CNN），在 DOS 下识别 28×28
二值手写数字（0–9）。全部运算为 **int8/int16 定点运算**，无浮点，可在真实的
8086/8088 机器上运行。

- 源码：`NN.ASM`（MASM 语法 推荐使用此版本） / `nn_digits.asm`（NASM 语法，同一网络）
- 权重：`net_weights.bin`（5174 字节，int8 定点，训练后导出）
- 输出：识别的数字 + ASCII 图，每次运行追加记录到 `RESULTS.TXT`

***

## 1. 网络总览

```text
输入  28×28 二值图 (0/1)                784 字节
        │
        │  C1 : 卷积，6 个 5×5 卷积核，valid，步长 1
        ▼
h1    6 @ 24×24                         ReLU，clamp 到 0..127
        │
        │  S2 : 2×2 平均池化（求和 >> 2）
        ▼
h2    6 @ 12×12                         864 字节
        │
        │  C3 : 卷积，16 个 5×5 卷积核（每个连接全部 6 个输入通道）
        ▼
h3   16 @ 8×8                           ReLU，clamp 到 0..127
        │
        │  S4 : 2×2 平均池化（求和 >> 2）
        ▼
h4   16 @ 4×4 = 256                     256 字节
        │
        │  F5 : 全连接 256 → 10
        ▼
得分  10 个 int16                         >> SH4 后取 argmax
                                          （并列取第一个）
        ▼
输出  数字 0–9
```

| 层      | 类型     | 输入尺寸    | 输出尺寸    | 卷积核       | 参数量                 |
| ------ | ------ | ------- | ------- | --------- | ------------------- |
| C1     | 卷积     | 1×28×28 | 6×24×24 | 5×5 ×6    | 150 权重 + 6 偏置       |
| S2     | 平均池化   | 6×24×24 | 6×12×12 | 2×2       | 0                   |
| C3     | 卷积     | 6×12×12 | 16×8×8  | 5×5×6 ×16 | 2400 权重 + 16 偏置     |
| S4     | 平均池化   | 16×8×8  | 16×4×4  | 2×2       | 0                   |
| F5     | 全连接    | 256     | 10      | —         | 2560 权重 + 10 偏置     |
| **合计** | <br /> | <br />  | <br />  | <br />    | **5110 权重 + 32 偏置** |

权重文件 5174 字节 = 6×(2+25) + 16×(2+150) + 10×(2+256)。

## 2. 各层运算详解

### C1 — 卷积层（二值输入，无需乘法）

对 6 个输出通道 k，在 24×24 个有效位置 (r,c) 上，与输入做 5×5 卷积：

```text
h1[k,r,c] = clamp( ( bias1[k] + Σ Σ w1[k,dr,dc] · g[r+dr,c+dc] ) >> SH1 , 0, 127 )
```

- **输入 g 是 0/1 二值**，所以"乘法"退化为条件加法：像素为墨时加上 int8 权重
  （符号扩展），为空时跳过。这是该实现最省时的一层（约 20 周期/项，见
  `NN.ASM` 的 `I_C1DC` 内循环：`mov al,[si]` → `test` → `jz 跳过` → `cbw` → `add`）。
- `SH1`（见 `nn_cfg.inc`，当前 2）：累加和算术右移 SH1 位后写入输出。
- 钳位到 0..127：负数清零（ReLU），超过 127 截断，保证输出仍是 int8 范围。

运算量：6×24×24×25 = **86,400 次条件加法**（0 次乘法）。

### S2 — 2×2 平均池化

```text
h2[k,r,c] = ( h1[k,2r,2c] + h1[k,2r,2c+1] + h1[k,2r+1,2c] + h1[k,2r+1,2c+1] ) >> 2
```

4 个字节求和（0..508，16 位足够），右移 2 位即除以 4。

运算量：6×12×12 = **3,456 次加法**。

### C3 — 卷积层（int8 × int8 真乘法）

16 个输出通道，每个连接全部 6 个输入通道（无 LeNet 原版的稀疏连接表）：

```text
h3[k,r,c] = clamp( ( sext16(bias2[k]) + Σ Σ Σ w2[k,ci,dr,dc] · h2[ci,r+dr,c+dc] ) >> SH3 , 0, 127 )
```

- 累加器为 **32 位**（`DX:BX`，DX 累加低 16 位、BX 按进位/符号扩展修正），
  乘法用 8086 的 `imul r8`（80\~98 周期）。
- `SH3`（见 `nn_cfg.inc`，当前 8）：算术右移 SH3 位。
- 每个输出位置要遍历 6 通道 × 5×5 = 150 项；实现上输入指针按行加 7、按通道
  加 84 在 12×12 的 h2 上滑动（`I_C3DR` / `I_C3CI`）。

运算量：16×8×8×150 = **153,600 次乘加（MAC）**。

### S4 — 2×2 平均池化

与 S2 相同，把 16\@8×8 缩成 16\@4×4。

运算量：16×4×4 = **1,024 次加法**。

### F5 — 全连接层 + argmax

10 个输出神经元，每个接收全部 256 个输入：

```text
score[o] = ( sext16(bias3[o]) + Σ w3[o,i] · h4[i] ) >> SH4     i = 0..255
digit    = argmax_o score[o]     （并列时取第一个：first-max-wins）
```

- 与 C3 一样用 32 位累加器（`DX:BX`）和 `imul`。
- 得分右移 `SH4`（来自 `nn_cfg.inc`）后用 `cmp dx,best / jle` 比较，只比低
  16 位即可——前提是 `SH4` 足够大，保证 `|acc3>>SH4| ≤ 32767`。若 `SH4`
  偏小，高位移出的部分被丢弃，大负值会截断成正数被误选。

运算量：10×256 = **2,560 次乘加**。

### 段寄存器注意（MASM/EXE 版）

`[BP]` 的默认段是 **SS**，不是 DS；`ASSUME` 不改变这条硬规则。`h1`、`w2`
都在 DSEG，本程序用 BP 做游标访问它们时必须显式写 `ds:[bp]`：

```asm
I_C1ST: mov     ds:[bp],dl      ; h1 写入
I_C3DC: mov     al,ds:[bp]      ; w2 权重读取
```

`[BX]`/`[SI]`/`[DI]` 默认就是 DS，无需前缀。NASM 的 .COM 版没有这个问题，
是因为 .COM 里 `DS == SS`，`[bp]` 恰好指向同一段。

## 3. 定点数规则汇总

| 数据               | 表示                                  | 范围            |
| ---------------- | ----------------------------------- | ------------- |
| 输入像素 g           | 1 字节，0 或 1                          | 二值            |
| 层间激活 h1/h2/h3/h4 | 1 字节无符号                             | 0..127        |
| 全部权重 w           | 1 字节有符号（int8）                       | -128..127     |
| 全部偏置 bias        | 2 字节有符号（int16），读入时符号扩展              | -32768..32767 |
| 卷积/全连接累加器        | 32 位（DX:BX）                         | int32         |
| 缩放               | 算术右移 SH1 / SH3 / SH4（`nn_cfg.inc`） | 来自训练配置        |
| 非线性              | ReLU = `clamp(x, 0, 127)`（卷积层）；池化层无 | <br />        |

移位常量的作用：训练时每层输出的数值幅度不同，推理时用固定的右移把累加
结果重新缩放回 int8 的 0..127 表示范围，等价于"量化除法"，避免溢出。

## 4. 权重文件布局（net\_weights.bin，5174 字节）

小端序，顺序排列：

```text
偏移        内容                              大小
0x0000      C1: 6 × [ bias(i16) + 25×w(i8) ]   162 字节
0x00A2      C3: 16 × [ bias(i16) + 150×w(i8) ] 2,432 字节
                （每通道 150 项 = 6 通道 × 5×5）
0x09E2      F5: 10 × [ bias(i16) + 256×w(i8) ] 2,580 字节
0x1436      结束（共 5,174 字节）
```

代码里逐通道顺序读取：读完本通道偏置和 150/25/256 个权重后，文件指针恰好
落在下一通道的偏置上（`NN.ASM:445` 处的注释）。

## 5. 输入与运行

- **输入格式**：28 行 × 28 字符的文本。`1` `#` `*` 视为墨（1），其余字符视为空白（0）。
- **文件模式**：`NN.EXE IMAGE.TXT` — 读入解析后推理，打印 28 行 ASCII 图 + `PREDICT: n`。
- **键盘模式**：`NN.EXE` — 逐行输入 28 行（支持退格、ESC 随时退出），之后
  `ESC=退出，其他键=下一张`。
- **日志**：每次推理把 ASCII 图与结果写入 `RESULTS.TXT`。

构建：

```text
MASM NN,NN,NN;
LINK  NN;
```

## 6. 运算量与性能

| 层      | 加法            | 乘法 (imul)     |
| ------ | ------------- | ------------- |
| C1     | 86,400（条件加）   | 0             |
| S2     | 3,456         | 0             |
| C3     | 153,600（累加部分） | 153,600       |
| S4     | 1,024         | 0             |
| F5     | 2,560（累加部分）   | 2,560         |
| **合计** | \~247,000     | **\~156,000** |

8086 的 `imul r8` 需要 80–98 周期，C3 的 15 万次乘法占了全部运行时间的约
90%，单次推理约 2,800 万个时钟周期：

| 机器                    | 主频       | 单次推理    |
| --------------------- | -------- | ------- |
| IBM PC/XT（8088，8 位总线） | 4.77 MHz | ≈ 8 秒   |
| 8086 兼容机              | 4.77 MHz | ≈ 6 秒   |
| PS/2 30 型（8086-2）     | 8 MHz    | ≈ 3.5 秒 |
