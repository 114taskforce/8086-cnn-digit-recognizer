# tool 工具使用说明

本目录包含 8086 手写数字识别项目的**手绘输入工具**：用鼠标画数字，实时预览识别结果，并导出供 DOS 程序 `nn.com` 识别的文本文件。

## 文件

| 文件               | 说明     |
| ---------------- | ------ |
| `draw_digits.py` | 画板工具主体 |
| `draw.bat`       | 双击启动入口 |

## 启动

- 双击 `draw.bat`

## 界面与操作

```
┌──────────────┬─────────────┐
│              │  PREDICT: 9 │ ← 实时识别结果
│   28×28 画板  │  [细][中][粗] │ ← 画笔粗细
│  (左侧网格)   │  [清空 (C)]  │
│              │  0 1 2 3 4   │ ← 点击 = 保存
│              │  5 6 7 8 9   │
└──────────────┴─────────────┘
```

| 操作             | 效果                             |
| -------------- | ------------------------------ |
| **左键拖动**       | 画墨迹                            |
| **右键拖动**       | 擦除                             |
| **细 / 中 / 粗**  | 切换画笔大小（1/3/5 像素见方）             |
| **C 键 / 清空按钮** | 清空画板                           |
| **数字键 0-9**    | 以该数字为标签保存当前画板到文件（handmade文件夹下） |

画的时候建议**居中、写大一点**。

## 实时预测说明

右侧 `PREDICT: n` 每次落笔即刷新，内部跑的是与 `nn.exe` **逐位一致**的定点 CNN 推理：

- 权重直接读取 `input model\net_weights.bin`（重训后需要重新复制）
- 移位参数自动从 `asm\nn_cfg.inc` 解析（重训后需要重新复制）
- 层布局、tap 顺序、clamp、argmax 均与汇编代码相同——画板显示的结果就是 DOS 里会得到的结果

## 保存与 DOS 识别

按数字键（如 `9`）后，画板保存为：

```
emu\handmade\h9_<时分>.txt     （如 h9_1432.txt，DOS 8.3 兼容文件名）
```

文件格式为 **28 行 × 28 字符**：`#`=墨迹、`.`=空白、CRLF 换行——与 `nn.exe` 文件输入格式完全一致。

在 DOSBox 中识别：

```
C:\> nn HANDMADE\H9_1432.TXT
```
